# Video Toolbox v1.1

Финальная локальная версия медиаконвертера: публичная ссылка → MP4, MP3 или расшифровка TXT/SRT/VTT.

Интерфейс сохранён в исходном тёмном стиле. Реальную обработку выполняет локальный backend на FastAPI, yt-dlp и FFmpeg.

## Что уже работает

- анализ публичной ссылки и получение настоящих метаданных;
- определение доступных разрешений;
- скачивание и объединение видео/аудио в MP4;
- извлечение аудиодорожки в MP3: 128, 192 или 320 kbps;
- локальная расшифровка речи через Whisper;
- автоматическое определение русского, английского, словенского и других языков;
- экспорт расшифровки в TXT, SRT и VTT;
- предпочтение форматов без признака водяного знака;
- удаление временного файла после передачи браузеру;
- ограничение до двух одновременных загрузок;
- блокировка локальных и служебных URL.

Важно: приложение получает чистый исходный поток только тогда, когда площадка его действительно предоставляет. Оно не стирает, не замазывает и не обрезает водяной знак, уже вшитый в изображение. Используйте только собственные материалы или видео, на загрузку которых у вас есть разрешение.

## Первый запуск на Windows

Понадобятся:

1. Node.js (у вас уже установлен).
2. Python 3.11 или новее: https://www.python.org/downloads/
3. FFmpeg. Установить в PowerShell:

```powershell
winget install Gyan.FFmpeg
```

После установки FFmpeg закройте и заново откройте PowerShell.

Затем откройте папку проекта и дважды щёлкните `start_windows.bat`. Скрипт сам создаст Python-окружение, установит зависимости, запустит backend и frontend и откроет:

```text
http://127.0.0.1:5173
```

Можно запустить из PowerShell:

```powershell
cd C:\путь\к\video-toolbox
.\start_windows.bat
```

Здесь используется `npm.cmd`, поэтому ограничение PowerShell на запуск `npm.ps1` не мешает работе.

При первой расшифровке локальная модель Whisper загрузится автоматически. Это разовая загрузка; затем распознавание сможет работать без платного API. Модель занимает несколько сотен мегабайт, а скорость зависит от процессора.

## Обновление поддержки сайтов

Площадки регулярно меняют свои страницы. Если знакомая ссылка перестала работать, запустите:

```powershell
.\update_backend_windows.bat
```

После обновления перезапустите проект.

## Ручной запуск для разработки

Backend:

```powershell
py -3 -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r backend\requirements.txt
.\.venv\Scripts\python.exe -m uvicorn backend.app:app --reload --host 127.0.0.1 --port 8000
```

Frontend во втором окне:

```powershell
npm.cmd install --prefix frontend
npm.cmd run dev --prefix frontend
```

Проверка backend: `http://127.0.0.1:8000/health`.

## Развёртывание на Railway

Production-сборка запускает frontend и backend одним Docker-контейнером. В Railway подключите GitHub-репозиторий, укажите корневую папку `/video-toolbox`, а путь Config as Code — `/video-toolbox/railway.json`.

Добавьте переменную:

```text
ALLOWED_ORIGINS=https://video-toolbox-nikita-preview.grizaknikita9.chatgpt.site
```

После успешной сборки откройте `Settings → Networking → Generate Domain`. Проверка API: `https://ваш-домен.railway.app/health`. Главная страница открывается по адресу домена без `/health`.

## Ограничения v1.0

- приватные, платные, DRM-защищённые и требующие входа видео не поддерживаются;
- плейлист не скачивается целиком;
- максимальный размер одного файла по умолчанию — 2 ГБ;
- для постоянной страницы в интернете потребуется отдельный backend-сервер с FFmpeg и дисковым пространством.
